
## Project Name : 
 **বাজার দর (BazarDor)

 **বাজার দর (BazarDor) is a web application designed to help users explore daily market prices of essential products in Bangladesh. It provides an easy-to-use interface where users can check product prices, compare market rates, browse categories, and stay informed about daily price changes.


 ## Key Features:

 **Daily Price Updates- Explore the latest available prices of essential products and track daily price changes.

 **Product Categories- Browse products by category to find the items you need quickly.

 **Price Comparison — Compare prices across different markets and make informed purchasing decisions. 

 **Product Details — View detailed product information, including current prices, previous prices, units, and market-wise rates. 

 **User Authentication & Profile — Sign up, sign in, manage your profile, and access account-related features securely.

 ##Technologies Used-
 **Next.js — React framework for building modern web applications.
 **React.js — Component-based user interface development.
 **TypeScript — Type-safe and maintainable code.
 **Tailwind CSS — Utility-first styling for responsive designs.
 **DaisyUI — Ready-to-use UI components.
 **Better Auth — User authentication and session management.
 **REST API — Fetching product, category, and market price data.
**React Icons — Icons for an intuitive user interface.
